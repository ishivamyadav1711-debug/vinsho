CORK PRODUCT IMAGE PACKAGE

This package contains the product images and an explicit image-to-product mapping.

IMPORTANT MAPPING NOTES
- Feather Printed Tabletop T.T. Planter: only the first supplied image is included. The second supplied image was identified as Cork Belly Planter and is NOT included here.
- Natural Bark Planter: only the first supplied image is included. The second supplied image was identified as Round Linear Planter and is NOT included here.
- Passport Holder Granoco Combo-19: only the passport-holder image is included. The other supplied image was identified as Small Calendar Combo-36.
- Cork Canvas Sleeve Combo 10: the second image is the NEWLY SUPPLIED image (e65ce08e...); the previously used second image is intentionally NOT included.

FILES
- product-image-mapping.csv: one row per image, useful for spreadsheet/import workflows.
- product-image-mapping.json: grouped mapping by product slug.
- Each product has its own folder; 01.jpg is the primary image and subsequent images are gallery images.
